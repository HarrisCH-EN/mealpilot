# 界面设计规范

更新时间：2026-09-18（Asia/Shanghai）

## 1. 规范来源

当前实现以 `miniprogram/app.wxss` 和 `miniprogram/styles/recipe-theme.wxss` 为准。下面的令牌直接对应现有 CSS 变量，不能仅凭历史设计稿新增另一套颜色或字体。

## 2. 视觉令牌

| 类别 | 当前值 |
| --- | --- |
| 主色 | `#ff385c` |
| 主色按下 | `#e00b41` |
| 禁用主色 | `#ffd1da` |
| 主文字 | `#222222` |
| 正文 | `#3f3f3f` |
| 次要文字 | `#6a6a6a` |
| 画布 | `#ffffff` |
| 柔和表面 | `#f7f7f7` |
| 细边框 | `#ebebeb` |
| 输入/卡片圆角 | `16rpx` / `28rpx` |
| 大圆角 | `40rpx` |
| 常用间距 | `8rpx`、`16rpx`、`24rpx`、`32rpx`、`48rpx` |

字体栈优先使用系统字体，并包含中文系统字体 fallback；项目不把外部字体文件作为运行时依赖。

## 3. 组件规则

- 页面左右内边距为 `32rpx`，底部为 `48rpx`。
- 卡片使用 1rpx 浅边框、`28rpx` 圆角；需要浮层层次时使用现有 `shadow-float`。
- 主按钮最小高度 `88rpx`，次按钮 `72rpx`；按钮、关闭、搜索等触控目标不得小于现有实现。
- 输入框和选择器最小高度 `88rpx`，文本域最小高度 `220rpx`。
- 标签采用胶囊形，选中态使用深色底和白字；不可用态降低对比度但保留可读性。
- 底部弹层使用遮罩、安全区内边距和顶部拖拽条，不覆盖系统手势区域。

## 4. 页面状态

推荐页、菜单页、菜谱页和设置页统一提供 loading、empty、error、success 状态。加载时使用骨架或明确文案，空状态给出下一步操作，错误状态提供重试；删除、退出家庭、移除成员等破坏性动作需要确认。

## 5. 当前页面重点

- 推荐：先选条件，再展示候选卡片和理由；应用与换一组操作需要区分 loading 和成功反馈。
- 菜单：按日期/餐次分组，菜单项操作保持幂等，空菜单提供添加入口。
- 菜谱：搜索、封面 fallback、详情和表单共享菜谱字段；封面临时 URL 失效时仍显示菜名和内容。
- 设置/家庭：把账号、家庭角色、偏好、忌口、标签管理分组，管理员操作与普通成员操作有清晰权限提示。

## 6. 修改验收

修改 UI 后至少检查四类状态、系统安全区、键盘遮挡、长中文标题、无封面图片、网络失败和重复点击。视觉改动必须同步对应页面测试，避免只更新设计说明而不更新实际令牌。
