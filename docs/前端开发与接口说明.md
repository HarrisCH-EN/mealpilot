# 前端开发与接口说明

更新时间：2026-09-18（Asia/Shanghai）

## 1. 工程边界

小程序根目录是 `miniprogram/`，入口为 `app.js`、`app.json`、`app.wxss`。请求、会话、家庭状态和展示工具位于 `miniprogram/utils/`；通用视觉令牌位于 `app.wxss` 与 `styles/recipe-theme.wxss`。

生产传输配置由 `miniprogram/config.js` 提供：普通 API 与图片上传通过 `wx.cloud.callContainer` 访问 `cloud1-d1gvr0mwv39a12cbd` 中的 `mealpilot-api`，路径以 `/api` 开头。开发环境仍使用 localhost 的 `wx.request` / `wx.uploadFile`。旧公网地址仅用于历史 `/uploads/...` URL 的展示兼容。

## 3. 会话与全局状态

`app.js` 初始化本地会话，`utils/auth.js` 负责 token 保存、失效和退出。未登录时全局闸门只允许登录页；401 清理会话并回到登录页。家庭切换和成员资料通过家庭 API 刷新，不把页面缓存当作权限依据。

## 4. 主要接口域

后端以 `/api` 为前缀，路由模块位于 `server/src/routes/`：

| 域 | 典型接口 | 说明 |
| --- | --- | --- |
| Auth | `POST /auth/wechat-login`、`GET /auth/me` | 登录、当前用户 |
| Family | `/families`、`/families/:id/members` | 家庭与角色 |
| Recipe | `/recipes`、`/recipes/:id` | 菜谱 CRUD 与软删除 |
| Upload | `/uploads/recipe-cover`、`/uploads/avatar` | 私有 Storage 上传 |
| Menu | `/menus`、`/menus/:id/items` | 菜单与菜单项 |
| Recommendation | `POST /recommendations`、候选与应用接口 | 推荐运行、候选和应用 |
| Preference / Restriction | `/preferences`、`/restrictions` | 成员偏好与忌口 |
| Tag | `/tags` | 系统标签与家庭自定义标签 |
| Feedback | `/menu-items/:id/feedback` | 菜单项反馈 |
| Insight | `/insights?days=7\|30` | 家庭基础洞察 |

请求体和响应字段以对应 route/service 实现为准；文档不复制容易失真的完整 JSON 样例。

## 5. 菜谱与媒体字段

菜谱响应可能同时包含：

- `coverFileId`：稳定的 CloudBase File ID，写入和删除使用它。
- `coverUrl`：临时 HTTPS 展示地址，可能过期，不能持久化为主键或长期配置。

系统菜谱的封面来自 Storage 的 `system/recipes/` 路径。没有映射的菜谱必须显示 fallback，不得把开发机路径拼进请求。

## 6. 推荐交互

推荐页提交目标日期、餐次、标签偏好、准备时间、菜品数量和结构。成功后展示最多 3 个已持久化候选；“换一组”读取同一运行的其他候选，“应用”携带 `candidateId`，服务端再次校验家庭、成员、忌口、结构和状态后写入菜单。

## 7. UI 状态约定

每个异步页面至少区分 loading、empty、error、success 四种状态；按钮在请求期间禁用并保留可恢复的错误操作。底部弹层需要安全区内边距，删除和移除成员使用明确的二次确认。详细令牌与组件尺寸见[界面设计规范](界面设计规范.md)。
