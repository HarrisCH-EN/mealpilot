# 设置页现代面板风格设计

## 目标

将微信小程序设置页重构为“Modern Family Dashboard”结构：以纯白画布、轻量粉色强调和统一的 iOS-like 设置组，降低旧版长列表的视觉负担，同时保留现有真实业务入口和交互。

## 设计方向

- 页面画布为 `#FFFFFF`，禁止大面积渐变、玻璃拟态和装饰性阴影。
- 主要文字使用 `#171717`，次级文字使用 `#8F8F8F`，不可用状态使用 `#B0B0B0`。
- 普通设置组使用 `#FAFAFA`，家庭快捷卡使用 `#FFF5F7`，品牌粉 `#FF4F7B` 只用于头像文字、快捷卡图标、少量状态和已有 TabBar。
- 页面左右内边距统一为 `32rpx`；间距仅使用 8/12/16/20/24/32/40/48rpx 级别。
- User Card 圆角 `28rpx`，Dashboard Card 与 Settings Group Card 圆角 `24rpx`；组内行不再嵌套圆角。
- 图标统一为现有设置图标资源，尺寸统一为 `40rpx`，通过同一布局盒对齐。

## 页面结构

1. Header：标题“设置”和副标题“用美食，连接家人的每一餐。”，右侧为可选的 CSS 极简家庭装饰。页面使用 custom navigation，但只通过 `statusBarHeight` 与 `wx.getMenuButtonBoundingClientRect()` 动态计算顶部留白；不自行绘制微信胶囊或返回按钮。
2. 用户账户卡：头像、真实展示名、本地演示账户和 chevron。点击沿用当前本地演示账户提示/登录逻辑。
3. 家庭管理：三列等宽快捷卡，分别对应家庭信息、家庭邀请码和家庭成员。家庭信息使用已加载的家庭数据；邀请码复制；成员卡展开已加载的成员列表。
4. 饮食与账户：统一高度的设置组。家庭口味偏好、成员忌口、账号保留为明确的“即将开放/演示模式”状态，并继续复用 `showUnavailable`。
5. 更多：推荐洞察（仅在有家庭时显示）、帮助与反馈、关于我们、清理缓存。洞察继续请求 `/insights`；关于我们继续导航；清理缓存继续只操作临时缓存 key，并保留确认弹窗。
6. 底部安全区：页面内容底部 padding 包含 TabBar 视觉高度和 `env(safe-area-inset-bottom)`。

## 数据与交互约束

- 不修改数据库 Schema、后端 API 或其他 Tab 页面。
- 不增加虚假的成员数量、邀请码、缓存容量或入口。
- 家庭成员数量来自 `/families/current` 的 `members.length`；邀请码来自 `membership.invite_code` 或家庭数据；缓存不读取到真实容量时不显示容量文案。
- 所有真实可点击元素使用现有处理函数，新增的家庭信息卡只展示已加载的真实数据并以轻量 modal 呈现，不创建新页面。
- 可用控件使用 100–150ms 的 pressed 状态；不可用入口保留清晰状态提示，不使用可误导的 chevron。

## 验证

- 检查 WXML 中所有事件都有 Page handler。
- 检查设置页只改动自身 WXML/WXSS/JS/JSON 与本规格文件。
- 运行现有前端/后端测试与脚本检查，并确认没有 API、Schema 和其他 Tab 页面改动。
- 在窄屏媒体规则下验证三列快捷卡均分、邀请码不换行、底部内容不被 TabBar 遮挡。
