# 登录页布局调整设计

## 目标

调整微信小程序登录页的首屏布局，使页面不产生上下滚动；将 logo 放在内容区域顶部的水平中心；将品牌中文名“饭有谱”作为更大的主标题，并将英文名“MealPilot”作为更小的副标题置于其下。

## 方案

- 保留现有登录页 WXML 结构、按钮事件、会话恢复、资料完善弹窗和错误提示逻辑。
- 在品牌区内保留 logo、品牌文案和副标题，但把品牌文案顺序调整为中文在上、英文在下。
- 使用固定视口高度的页面容器，并通过 `overflow: hidden` 禁止页面滚动；内容使用纵向 flex 布局在安全区内分配空间。
- 采用项目既有颜色令牌和卡片/按钮风格，仅收紧垂直间距和品牌字号，使常见手机屏高下登录卡片与底部说明都能在首屏可见。
- 通过登录页现有测试和静态检查验证：资源、文案、事件绑定与登录逻辑不变，且样式包含固定视口与品牌层级规则。

## 约束与验收

1. 登录页不出现页面级上下滚动。
2. logo 位于页面内容顶部中间。
3. “饭有谱”位于 logo 下方且字号大于“MealPilot”。
4. “MealPilot”位于“饭有谱”下方，保留英文副标题 “Plan less. Eat better.”。
5. 微信登录、本地开发登录、资料完善弹窗和跳转逻辑继续使用现有实现。
6. 不修改全局设计令牌或其他页面的滚动行为。
