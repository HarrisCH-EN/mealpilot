# 首页问候与今日菜单时段默认设计

## 目标

按设备本地时间显示首页问候语，并在菜单页查看今天时默认打开对应餐次；不改变任何 API、数据库、菜单数据、推荐逻辑或跳转行为。

## 共享时间工具

在 `miniprogram/utils/ui.js` 提供可传入小时数的纯函数，供页面和测试复用：

- `getGreeting(hour)`：05–08 返回“早上好，”，09–11 返回“上午好，”，12–17 返回“下午好，”，18–04 返回“晚上好，”。
- `getCurrentMealType(hour)`：05–10 返回 `breakfast`，11–16 返回 `lunch`，17–04 返回 `dinner`。

页面初始化以 `new Date().getHours()` 取设备本地小时，并传入上述函数。纯函数不访问小程序 API，也不读取或写入存储。

## 首页

推荐页初始 data 中计算 `greeting`，并将既有固定“晚上好，”展示替换为该绑定。仅影响展示文字；`generate`、偏好、loading 与结果状态不变。

## 菜单页优先级

菜单页确定默认卡片时按以下顺序：

1. 从菜谱页带回的 `focus` 上下文指定餐次。
2. 选中日期是今天时，按 `getCurrentMealType` 选择早餐、午餐或晚餐。
3. 选中日期不是今天时，保留现有“有菜优先”的选择行为。

时间默认只应用于首次加载和“回到今天”；用户手动点击或滑动餐次不被重新覆盖。

## 验证

- 为两条纯函数覆盖每个时段边界与跨午夜情况。
- 为菜单今日/非今日/外部 focus 三种优先级写静态或单元测试。
- 运行小程序测试与服务端菜单、推荐相关测试，确认 API 和数据层未变化。
