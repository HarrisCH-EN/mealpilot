# 饭有谱微信小程序 UI v1 设计规格

## 目标

将现有原生微信小程序升级为简约、克制、有家庭温度的配餐工具。视觉语言参考国泰航空 App 的留白、深青绿层级和圆润卡片，并引入“思源宋体标题 + 思源黑体正文”的中文字体角色分工。

## 视觉系统

- 背景：暖白 `#F4F5F2`；卡片：纯白 `#FFFFFF`；柔和区块：`#E9EFEC`。
- 品牌色：青绿 `#0B6B65`，深青 `#17483F`；少量陶土色 `#C77955` 只承担提示和强调。
- 标题字体栈：`"Noto Serif SC", "Songti SC", STSong, serif`；正文与控件：`"Noto Sans SC", "PingFang SC", sans-serif`。
- 大标题允许宋体呈现编辑感；数据、按钮、标签与长正文保持黑体，避免影响可读性。
- 卡片主要依靠色块、圆角和留白区分，减少硬边框和重阴影。
- 顶部不显示“饭有谱”文字；各页只保留页面自身标题。

## 页面与交互

### 推荐

- 展示日期、餐次、人数、最长烹饪时长和推荐模式。
- 推荐结果保留评分、理由、总耗时、重新生成和应用到菜单。
- 生成和应用期间禁用重复操作；失败在页面内显示并允许重试。

### 菜单

- 以日期为主轴展示早餐、午餐、晚餐，并保留前后日期切换。
- 顶部“加菜”真实跳转到菜谱页；菜品可以二次确认后删除。
- 空餐次和全天空状态均提供明确的手动加菜入口。

### 菜谱

- 左侧约四分之一宽度为分类导航，右侧约四分之三为菜品卡片列表。
- 卡片点击进入菜品详情；右下角加号打开“加入菜单”底部弹层。
- 弹层必须选择日期与餐次，可填写备注，并调用现有 `/menus/items` 接口。
- 新增与编辑使用完整表单，支持标题、分类、耗时、难度、份量、描述、步骤和食材明细。
- 删除菜谱保留二次确认与权限错误反馈。

### 设置

- 保留演示登录、创建/加入家庭、邀请码复制、成员列表和基础洞察。
- 偏好、忌口、反馈入口只显示“即将开放”，不制造可保存的假交互。

### 底部导航

- 继续使用原生四 Tab：推荐、菜单、菜谱、设置。
- 每个 Tab 提供成对图标：未选中为空心线框，选中为实心青绿色。
- 图标和文字均使用原生 TabBar 状态切换，避免无响应装饰。

## 状态与约束

- 每页具备加载、空数据、网络错误、成功反馈和危险操作确认。
- 保持原生 WXML/WXSS/JavaScript，不引入云开发或第三方 UI 框架。
- 保持现有 API 路径和字段；只新增前端页面、纯函数工具和视觉资源。
- 图片缺失时使用抽象餐盘占位；存在 `coverUrl` 时允许展示真实封面。

## 验收

- 现有后端流程全部可用：登录、推荐、应用、菜单加删、菜谱查增改删、家庭与洞察。
- 菜谱加号可选择任意日期和早餐/午餐/晚餐并成功写入菜单。
- 顶部不出现“饭有谱”标题，Tab 图标严格区分空心/实心状态。
- 主要触控区域不小于 44px 等效尺寸，窄屏下无横向溢出。
