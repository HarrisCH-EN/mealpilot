# 推荐加载水波过渡设计

## 范围

仅为推荐页从初始/加载状态进入现有推荐结果页增加视觉过渡。水波以既有 `screen === 'loading'` 为条件渲染，不增加 JavaScript 状态、事件、接口调用或计时器。

## 视觉行为

- 用户点击既有“帮我选”按钮后，原 `generate` 立即将页面置为 loading。
- 两层品牌粉色圆环从 CTA 中心向外扩散约 700ms。
- 初始页内容同步缓慢淡出，水波层本身不拦截或新增交互。
- 接口返回后，现有结果页和既有 `result-enter` 动画照常出现；错误状态、偏好抽屉与其他流程不变。

## 实现边界

- 只改 `miniprogram/pages/recommend/index.wxml` 与 `index.wxss`，以及相应的静态视觉检查。
- 水波为条件展示节点和页面专属 CSS keyframes；不使用渐变背景、图片资源或自定义导航。
- 不改 `index.js`、API、请求参数、数据结构、数据库或页面跳转。

## 验证

- 静态测试断言水波节点受既有 loading 状态控制，`generate` 绑定及推荐 API 调用仍保留。
- 执行所有小程序测试及服务端推荐契约测试。
