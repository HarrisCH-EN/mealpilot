# 未加入家庭空状态统一设计

## 目标

统一推荐、菜单、菜谱三个 Tab 在用户尚未加入家庭时的视觉与文案。保留各页面原有顶部标题和副标题，不修改鉴权、数据请求或跳转逻辑。

## 视觉方向

采用轻盈、克制的家庭入口卡，延续现有白底、深色正文和品牌粉 `#ff385c` 的 Airbnb 风格。

- 三个页面使用相同的卡片尺寸、间距、边框、圆角和按钮。
- 卡片位于页面标题下方，保持充足留白，不垂直居中撑满页面。
- 使用现有家庭图标 `/assets/icons/settings/family.png`，置于浅粉圆形底中。
- 标题统一为“还没加入家庭”。
- 说明限制为一句短文案，最多两行。
- 主按钮统一为“创建或加入”，使用品牌粉胶囊按钮。
- 不增加插画、渐变、阴影堆叠或新的交互。

## 页面文案

| 页面 | 顶部标题 | 空状态说明 |
| --- | --- | --- |
| 推荐 | 保留现有推荐页标题 | 先加入家庭，再为一家人搭配一餐。 |
| 菜单 | 保留“今日菜单”及副标题 | 先加入家庭，再安排今天的菜单。 |
| 菜谱 | 保留“菜谱”及副标题 | 先加入家庭，再收好家里的拿手菜。 |

三个页面的空状态标题均为“还没加入家庭”，按钮均为“创建或加入”。

## 组件规格

- 卡片：左右随页面安全边距铺开，统一圆角和细边框，背景为白色。
- 图标容器：圆形浅粉底，家庭图标保持深色，避免三个页面出现不同图形语言。
- 标题：深色、加粗、居中。
- 说明：灰色、居中、紧凑行高。
- 按钮：固定视觉宽度与高度，圆角胶囊，品牌粉背景，白色文字。
- 窄屏：保持同一结构，仅收紧卡片水平内边距和说明宽度。

## 实现边界

- 在全局样式中增加可复用的家庭空状态样式，三个页面只保留必要的页面定位覆盖。
- 更新三个页面的空状态 WXML，使结构和类名一致。
- 继续调用各页面已有的 `goFamilySetup`，跳转仍为设置 Tab。
- 不修改正常家庭状态、TabBar、接口请求、页面标题或业务代码。

## 验收标准

- 三个页面的空状态结构、卡片、图标、标题和按钮视觉一致。
- 每页说明只有一句，且按钮文字统一。
- 页面原有顶部标题和副标题保留。
- 所有原有页面事件仍有对应处理函数，`goFamilySetup` 行为不变。
- 小程序自动化测试通过，并新增覆盖统一结构和文案的回归测试。
